trustless-ai in practice

The stack

Three layers for agents you never have to trust — and you recompute at every one, from proof to deploy:

  • recompute-kit — verify. Re-derive any claim from its primary artifact, tri-state.
  • agent bindings — the ERCs encoding identity, provenance, verification and settlement.
  • onchain-boiler-kit — ship. Deploy the whole stack, no code required.

The recompute mesh

Independent nodes re-run every proof node-side, not self-attested — the always-on audit runtime for the agent-standards family. Verify by recomputing, never by trusting.
