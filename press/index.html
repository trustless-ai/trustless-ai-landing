trustless-ai
About & Press

Infrastructure you never have to trust — only recompute.

trustless-ai is an open ecosystem of standards, reference implementations and tooling for AI agents: infrastructure anyone can provide, anyone can use, and everyone can verify by recomputing the proof. It is owned by no one.

What it stands for

Don't trust — recompute.

Nothing ships that a third party can't independently verify from public data. Every claim is re-derived from the primary artifact, pinned to an exact reference, and answered with a tri-state verdict — verified-good, verified-bad, or unverifiable. "Couldn't check" is its own answer, never a silent pass. There is no pitch here; the substance is the pitch.

Verify it yourself

Don't take this page's word for any of it — re-run it:

  • recompute-kit — the toolchain. Clone it and re-derive any claim yourself.
  • Conformance vectors — public inputs → expected outputs, one row per step; the canonical authority no implementation is trusted above.
  • agent-ercs — the interfaces and audited base implementations for every layer.
  • onchain-boiler-kit — deploy the stack yourself.
  • A live settlement proof — recompute a real mainnet outcome straight from its /proof.

The standards

The agent-standards family — each an ERC or a recomputable reference implementation:

  • ERC-8004 — agent identity registry
  • ERC-8274 — AI inference proof verification
  • ERC-8275 — reputation from recomputable inputs
  • ERC-8299 · WYRIWE — input provenance
  • ERC-8301 — agent execution / task dispatch
  • ERC-8312 — bounded agent actions
  • ConsultEscrow — pay-on-delivery settlement
  • ccip-router — the recompute mesh (nodes re-run proofs, never self-attested)
